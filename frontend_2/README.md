# CampusPlay

A frontend-only inter-class and inter-block sports management prototype. Built with React, Vite, TypeScript and Tailwind CSS; demo accounts and application data live in browser localStorage. No backend or API keys are used.

## Run

```sh
npm install
npm run dev
```

Use the **Student Demo** and **Organizer Demo** buttons on the login screen. The user menu in the workspace can switch between demo roles. To restore the original sample data, use **Reset demo data** on the student Profile page, or clear `campusplay-data-v1` from localStorage.
